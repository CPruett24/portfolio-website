# Chandler Pruett Portfolio

A modern software engineering portfolio built with Next.js, React, TypeScript, and Tailwind CSS.

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- shadcn/ui
- Framer Motion (planned)
- Vercel

## Features

- Professional developer portfolio
- AI project showcase
- Interactive project pages
- Responsive design
- Resume integration
- Case studies
- Future developer blog

## Projects

- JARVIS AI Assistant
- Vehicle AI Diagnostic Assistant
- VolunteerHub Backend

## Getting Started

```bash
npm install

npm run dev
```

Visit:

```
http://localhost:3000
```
